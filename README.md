# Από τα bits στα qubits: προσομοίωση κβαντικού υπολογιστή NMR

Διαδραστικό συνοδευτικό υλικό της εισήγησης «Από τα Bits στα Qubits: Πραγματικά Πειράματα και Αλγόριθμοι σε Κβαντικό Επεξεργαστή Πυρηνικού Μαγνητικού Συντονισμού», 21ο Πανελλήνιο Συνέδριο της ΕΕΦ (2026).
Ιωάννης Θεοδώνης, Σχολή Εφαρμοσμένων Μαθηματικών και Φυσικών Επιστημών, Εθνικό Μετσόβιο Πολυτεχνείο.

**Ζωντανή εκδοχή:** https://ioannis75.github.io/bits-to-qubits/

## Περιεχόμενο

- **Κινούμενη εισαγωγή (περίπου ενάμισι λεπτό).** Από τη μαγνητική τομογραφία του νοσοκομείου στην κβαντική υπολογιστική: πρωτόνια-μαγνήτες, παλμοί ραδιοκυμάτων, σήμα και εικόνα· μετά από τα bits στα qubits (διακόπτες, επαλληλία, μέτρηση, τέσσερα πλάτη μαζί) και η ίδια φυσική σε ένα μόριο που γίνεται κβαντικός υπολογιστής.
- **Προσομοίωση NMR.** Η μαγνήτιση ενός συνόλου πυρηνικών σπιν σε κίνηση: παλμοί ραδιοσυχνοτήτων, μετάπτωση, αποσυνοχή, ηχώ σπιν και σύζευξη J, μαζί με το σήμα FID, το φάσμα και τις ταλαντώσεις Rabi.
- **Συνθέτης κβαντικών κυκλωμάτων.** Κυκλώματα δύο qubits με μεταφορά πυλών και εκτέλεση σε προσομοιωμένο Gemini Mini ή Gemini Mini Pro. Τα αποτελέσματα περιλαμβάνουν πιθανότητες, εξέλιξη βήμα προς βήμα στη σφαίρα Bloch, πίνακα πυκνότητας από τομογραφία, φάσματα NMR και την ακολουθία παλμών κάθε κυκλώματος.

Την πρώτη φορά σε κάθε εργαλείο εμφανίζεται ένας σύντομος οδηγός χρήσης, που μπορεί να παραλειφθεί.

Πρόκειται για εκπαιδευτική προσομοίωση που δεν συνδέεται με πραγματική συσκευή. Οι παράμετροι θορύβου είναι ενδεικτικές και έχουν επιλεγεί ώστε να αναπαράγονται οι πιστότητες που δίνει ο κατασκευαστής για τους αλγορίθμους Deutsch και Grover.

*English:* Companion material for the invited talk "From Bits to Qubits: Real Experiments and Algorithms on a Nuclear Magnetic Resonance Quantum Processor". It contains a 90-second animated introduction linking hospital MRI and the step from bits to qubits to quantum computing, an animated NMR simulation and a two-qubit quantum circuit composer that runs circuits on a simulated SpinQ Gemini Mini / Mini Pro, with tomography, NMR spectra and pulse sequences. It is an educational simulation and is not connected to real hardware.
